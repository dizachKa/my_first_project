Ответы на вопросы для самоконтроля ПР5
## 1. Что такое Viewport meta tag и почему он важен для адаптивного дизайна?

`<meta name="viewport" content="width=device-width, initial-scale=1.0">` сообщает браузеру, что ширина страницы должна равняться ширине экрана устройства, а масштаб — 1:1. Без него мобильные браузеры отображают страницу в «виртуальном» окне ~980px и уменьшают её, что ломает адаптивность.

---

## 2. Какие основные подходы к созданию адаптивных макетов вы использовали (Fluid, Adaptive, Responsive)?

В работе сочетались:
- **Fluid** — `width: 100%`, `max-width`, относительные единицы (`%`, `rem`, `vw`).
- **Adaptive** — медиа-запросы с фиксированными брейкпоинтами (1024px, 768px, 480px).
- **Responsive** — комбинация fluid + медиа-запросов + `clamp()` для типографики.

---

## 3. Как работает Mobile First подход и в чем его преимущества перед Desktop First?

Mobile First — сначала пишутся стили для мобильных, затем через `min-width` добавляются стили для больших экранов. Преимущества: меньший объём CSS для мобильных, лучшая производительность, проще масштабировать вверх, соответствует современным приоритетам трафика.

---

## 4. Какие единицы измерения наиболее предпочтительны для адаптивной верстки и почему?

- `%` — для ширин контейнеров.
- `rem` — для типографики и отступов (зависит от `html font-size`).
- `em` — для компонентов, зависящих от локального размера шрифта.
- `vw/vh` — для полноэкранных секций.
- `clamp()` — для «плавной» типографики.

`px` используется только для границ и мелких деталей.

---

## 5. Как функция `clamp()` помогает создавать адаптивную типографику?

`clamp(min, preferred, max)` задаёт минимальный, предпочтительный (обычно `vw`) и максимальный размер. Например:
```css
font-size: clamp(1.5rem, 5vw, 2.5rem);
Шрифт плавно растёт с шириной экрана, но не меньше 1.5rem и не больше 2.5rem.

6. Какие основные брейкпоинты вы использовали и как определили эти значения?
1024px — планшеты в горизонтальной ориентации.

768px — планшеты в вертикальной / крупные телефоны.

480px — маленькие телефоны.

Значения выбраны по типовым размерам устройств и точкам, где макет начинает «ломаться».

7. Как медиа-запросы @media помогают создавать адаптивные стили? Приведите пример синтаксиса.
Медиа-запрос применяет CSS только при выполнении условия:

css
@media (max-width: 768px) {
    .nav-menu { display: none; }
    .nav-menu.active { display: flex; }
}
Так можно перестраивать сетку, скрывать/показывать элементы, менять типографику.

8. В чем разница между max-width и min-width в медиа-запросах и когда использовать каждый?
max-width — стили применяются, если ширина меньше указанной (Desktop First).

min-width — стили применяются, если ширина больше указанной (Mobile First).

Для Mobile First используют min-width, для Desktop First — max-width.

9. Как сделать изображения адаптивными и какие CSS-свойства для этого используются?
css
img {
    max-width: 100%;
    height: auto;
}
Дополнительно: srcset и sizes для выбора оптимального файла, <picture> для art direction.

10. Какие инструменты браузера помогают тестировать и отлаживать адаптивный дизайн?
DevTools → Device Toolbar (Chrome/Firefox) — эмуляция устройств.

Responsive Design Mode — изменение размеров окна.

Network Throttling — эмуляция медленного соединения.

Lighthouse — аудит производительности и доступности.

CSS Grid/Flex Inspector — визуализация сеток.
