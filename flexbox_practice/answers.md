# Ответы на вопросы для самоконтроля (ПР4)

## 1. Какое основное свойство CSS включает Flexbox и что происходит с дочерними элементами после его применения?

Основное свойство — `display: flex`. Оно превращает элемент во flex-контейнер, а все его прямые дочерние элементы становятся flex-элементами. Они начинают выстраиваться по главной оси (по умолчанию — в строку), получают возможность растягиваться, сжиматься и выравниваться.

---

## 2. В чем разница между `justify-content` и `align-items`?

- `justify-content` выравнивает элементы вдоль главной оси (main axis).
- `align-items` выравнивает элементы вдоль поперечной оси (cross axis).

Пример: если `flex-direction: row`, то `justify-content` работает по горизонтали, а `align-items` — по вертикали.

---

## 3. Что делает `flex-direction` и какие значения может принимать?

`flex-direction` задаёт направление главной оси:
- `row` (по умолчанию) — слева направо.
- `row-reverse` — справа налево.
- `column` — сверху вниз.
- `column-reverse` — снизу вверх.

От этого зависит, как выстраиваются элементы и как работают `justify-content` / `align-items`.

---

## 4. Объясните значение `flex: 1`. Что означают `flex-grow`, `flex-shrink` и `flex-basis`?

`flex: 1` — это сокращение для `flex-grow: 1; flex-shrink: 1; flex-basis: 0%`.

- `flex-grow` — во сколько раз элемент может увеличиваться.
- `flex-shrink` — может ли элемент сжиматься.
- `flex-basis` — базовый размер элемента до распределения свободного места.

---

## 5. Как работает `flex-wrap` и когда его использовать?

`flex-wrap` разрешает перенос элементов на новую строку, если они не помещаются:
- `nowrap` (по умолчанию) — всё в одну строку.
- `wrap` — перенос на новые строки.
- `wrap-reverse` — перенос в обратном порядке.

Используется для адаптивных сеток, где элементы должны переноситься на мобильных.

---

## 6. Чем отличается `align-content` от `align-items`?

- `align-items` выравнивает элементы **внутри одной строки**.
- `align-content` выравнивает **сами строки** во многострочном flex-контейнере (работает только с `flex-wrap: wrap`).

---

## 7. Как свойство `order` влияет на отображение элементов?

`order` меняет порядок flex-элементов без изменения HTML. По умолчанию `order: 0`. Чем больше значение, тем позже элемент. Полезно для смены порядка на мобильных без правки разметки.

---

## 8. Что такое главная ось (main axis) и поперечная ось (cross axis)?

- Главная ось задаётся `flex-direction` — вдоль неё выстраиваются элементы.
- Поперечная ось — перпендикулярна главной.

`justify-content` работает по главной оси, `align-items` — по поперечной.

---

## 9. Как создать адаптивный макет с помощью Flexbox без медиа-запросов?

Через `flex-wrap: wrap` и `flex: 1 1 250px`:
```css
.content {
    display: flex;
    flex-wrap: wrap;
    gap: 1rem;
}
.card {
    flex: 1 1 250px;
}

gap не создаёт отступов по внешним краям контейнера, не схлопывается, работает одинаково для строк и столбцов, не требует :last-child и :first-child. Проще и предсказуемее.
